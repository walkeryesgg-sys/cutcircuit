# 自媒体视频10分制上线标准

## 1. 硬性否决与评分上限

任何一项成立都必须列为致命问题：

- 黑屏、近黑屏、素材丢失、透明轨道未加载、异常冻结。
- 音视频流提前结束、人物一句话被截断、原声被旁白打断。
- 字幕明显不同步、字幕缺失、双语对应错误。
- 文字溢出、遮挡、裁切、超出安全区或数字卡片装不下内容。
- 人名、年份、地点、数字、引语或翻译存在事实错误。
- 出现“钩子、转场、此处插入”等制作标记。
- 爆音、长时间意外静音、音乐遮盖人声、音量突然跳变。
- 明显版权、肖像或隐私风险。
- 结尾突然中断、残留黑帧或未完成状态。
- 会员/高端内容中的全屏主素材明显失焦、低码率糊化、严重运动拖影或压缩涂抹，且未作为获批的历史档案例外处理。

“没有黑屏”不等于曝光合格。若人物面部、关键工程物体或字幕承载区连续偏暗，导致普通屏幕上难以辨认，即使未触发 blackdetect，也必须记为视觉体验问题；主体可见度不足覆盖成片 20% 以上时，“视觉版式”和“内容品味”均不得高于 8.5。

评分上限：

| 情况 | 总分上限 |
|---|---:|
| 黑屏、缺素材、解码失败、严重事实错误 | 5.9 |
| 明显不同步、文字溢出、语句被截断 | 6.9 |
| 前15秒无主题、冲突或观看回报 | 7.9 |
| 看完无法复述核心结论 | 8.0 |
| 廉价模板感、情绪或音乐品味不符 | 8.5 |
| 连续45秒无新信息或视觉推进 | 8.5 |
| 没有收藏、转发或追更理由 | 9.0 |

## 2. 十二项权重

| 维度 | 权重 | 核心证据 |
|---|---:|---|
| 技术完整性 | 12% | 黑帧、冻结、缺素材、编码、结尾 |
| 音画同步 | 9% | 口型、字幕、TTS、原声、切点 |
| 视觉版式 | 7% | 边界、层级、安全区、可读性 |
| 声音体验 | 8% | 人声、TTS自然度、响度、音乐融合 |
| 内容价值与深度 | 12% | 洞察、事实、边界、方法可迁移 |
| 叙事与故事 | 10% | 冲突、人物、因果、兑现 |
| 节奏与衔接 | 8% | 停顿、重复、镜头功能、章节推进 |
| 素材与证据 | 8% | 原声、案例、画面与观点的关系 |
| 记忆与教学 | 7% | 可复述结论、框架、故事和金句 |
| 内容品味 | 8% | 克制、统一、情绪准确、品牌辨识 |
| 算法与人的吸引力 | 8% | 首停、留存、完播、互动代理指标 |
| 平台及付费定位 | 3% | 目标用户、设备、课程价值 |

总分 = 各项原始分 × 权重，再换算为10分制；最后应用评分上限。

## 3. 算法与人的吸引力

分别判断：

- 第一帧是否有明确主体。
- 前3秒是否建立人物、行动、结果或冲突。
- 前15秒是否提出问题并承诺观看回报。
- 前30秒是否说明主题、价值和用户所得。
- 固定系列片头是否同时完成“人物/品牌可信度”和“观众能学到什么”；只有传奇履历而没有用户收益，吸引力项不得超过8.0。
- 每20–40秒是否出现新问题、证据、故事或结论。
- 中段是否持续兑现开头，而非拖延答案。
- 结尾是否回答开头并留下可转述结论。
- 是否具有收藏价值、转发理由、评论触发点和追更意愿。

仅用高/中/低描述潜力，不编造播放量或留存百分比。

## 4. 品味

检查：

- 视觉、音乐、字体、动效与内容定位是否一致。
- 是否廉价、过度营销、故作高深或过度煽情。
- 是否滥用大字、闪烁、轰鸣、光效和无意义快切。
- 素材是否提供证据、情绪或叙事推进。
- 画面是否明亮、干净、主体一眼可辨；不得把低码率伪1080p、失焦或高速拖影素材误判为高清。
- 调色是否只做适量曝光、曲线/中间调对比、色彩与末端轻锐化；检查光晕、塑料皮肤、噪点放大、色彩荧光、高光剪切和黑位压死。
- 文案是否口语但不低俗，深刻但不卖弄。
- 是否尊重观众，不靠虚假悬念和个人崇拜。
- 是否形成稳定、可识别的品牌语言。
- 实拍素材是否拥有足够大的视觉面积，而非被缩成装饰窗；证据型课程可参考图形约40%、实拍约60%，原声段人物/证据画面至少占画面65%。
- 检查整体亮度之外，还要检查主体亮度：深色品牌风可以保留黑位，但人物脸部、机械结构和关键动作必须一眼可辨。禁止通过全局降亮度、重黑遮罩或多层深色渐变把高清素材压成“有轮廓、没细节”。
- 素材切换是否出现裸露黑底或空槽；超过0.15秒的非设计近黑、超过0.25秒的无素材窗口按致命问题处理。
- 电影式片尾是否有完整情绪落点；英雄镜头建议持续至少6秒，最终品牌画面停留0.8–1.2秒。

## 5. 检查覆盖率

- 每个素材窗口：开始后0.2秒、中点、结束前0.2秒。
- 每个转场：转场前、交叠点、转场后。
- 每个文字卡片：最长文本和最大字号状态。
- 每段语音：首句、最长句、语种切换、结束句。
- 全片：至少一次线性播放。

在报告中给出覆盖率。覆盖不足时不得下“没有问题”的结论。
