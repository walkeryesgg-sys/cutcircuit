# 商业解释型视频写作手册

> 适用：长视频、商业/科技解释、公司或创业者故事。目标是让观众在复杂内容中持续获得“我看懂了一层”的回报，而不是模仿任何已研究创作者的口头禅、封面或危机话术。

## 1. 写前合同：先确定观众要更新什么认知

在脚本前填写：

| 字段 | 要求 |
| --- | --- |
| 表层认知 | 观众一开始以为发生了什么？ |
| 反常事实 | 哪个数字、行动、代价或冲突使旧解释不够？ |
| 隐藏问题 | 这背后的商业/权力/成本问题是什么？ |
| 解释发动机 | 一个公式、两项必要条件或一组冲突，贯穿整条片子 |
| 最大利益冲突 | 谁获益、谁付钱、谁承担风险、谁能阻止？至少填两项 |
| 事实桥 | 支持账号判断的最少三条事实及边界 |
| 账号判断 | 一句有立场的解释，明确是分析而非内部事实 |
| 观众带走什么 | 结束时能复述的判断规则或模型 |

`解释发动机` 不是章节名称，而是所有案例的筛选器。例：

`可重复的发射生意 = 单次成本 × 周转速度 × 稳定需求`

每个案例、数字、人物和镜头必须证明一个变量、揭示变量之间的冲突，或说明模型为何失效。无法服务模型的有趣资料也要删。

## 2. 包装合同：三种表面递进一个问题

| 表面 | 任务 | 合格检查 |
| --- | --- | --- |
| 封面 | 可见对象 + 一项具体商业张力 | 静音、缩略尺寸下仍知“谁在付什么代价/做什么选择” |
| 标题 | 补足非直觉问题、对象或后果 | 不是封面的大字复读 |
| 前 3–15 秒 | 给反常事实和第一份可视证明，立刻打开更深问题 | 没有问候、背景介绍或空情绪 |

先写这条链：`封面承诺 → 标题问题 → 开头证据 → 第一层答案 → 更深问题`。其中任一环无法回答前一环，重做包装或改选题。

## 3. 节拍链：每段都是一个小型侦探故事

为每个 15–45 秒内容单元填表：

| 节拍 | 此刻观众的问题 | 新证据/画面 | 人话翻译 | 商业后果 | 留下的更深问题 | 事实状态 |
| --- | --- | --- | --- | --- | --- |
| B01 |  |  |  |  |  | 已验证/归因/计划/判断 |

节拍必须有新的认知回报：

- 一个数字被转化为量级或可感结果；
- 一个术语被翻成生活语言；
- 一个角色的真实利益被揭开；
- 一个初步答案被限制、推翻或升级；
- 一个证据改变了上一段的意义。

“换 B-roll、复述结论、加情绪”不算回报。长视频需要轮换认知任务：机制 → 人物选择 → 比较 → 风险 → 系统总图；目的不是更快剪，而是避免观众连续几分钟只做同一件认知工作。

## 4. 长片默认推进

可按题材压缩，但不要省略逻辑职责：

1. **异常**：从观众熟悉的人、公司、结果或画面进入；马上给看似解释不了它的事实。
2. **旧答案为何不够**：承认常识的一部分，再指出它遗漏的变量。
3. **最小模型**：用一张图、一条公式或一个生活比喻把复杂系统压缩成可复述的骨架。
4. **连续验证**：每一段换一个变量、角色或案例，证明模型而非堆知识。
5. **冲突和代价**：显示谁会反对、谁承受成本，以及战略的脆弱处。
6. **回收与升级**：回到开头画面，给出比最初问题更大的判断；留下下一次如何判断的规则。

对于人物片，使用：`早期信号 → 关键下注 → 高光 → 代价/崩塌 → 新选择 → 不替观众作轻率判决`。人物的戏剧性应来自真实选择和后果，不来自揣测心理。

## 5. 证据、判断和冲突

视频必须同时有：

- **事实锚点**：日期、数据、合同、原始画面、采访、文档或已验证结果；
- **账号判断**：解释这些事实所揭示的利益、权力、压力、战略或文明意义；
- **真实冲突**：雄心与可行性、速度与风险、短期经济性与长期基础设施，或两种有证据的利益取舍。

判断允许有情绪、画面和文学性。它要紧贴事实桥，且清楚属于账号观点。禁止把推断写成当事人的秘密动机、来源没有说过的引语、或已经发生的能力。

## 6. 画面必须帮助解释，而非陪衬

在节拍台账中为每个关键句写“视觉证明”：

- 讲成本：给成本构成、制造/回收动作或可比较数量；
- 讲客户：给订单、任务、服务对象或使用场景；
- 讲控制权/资本：给股权/融资结构、公开文件或角色关系；
- 讲约束：给物理限制、失败现场、产能节奏或明确后果。

一段画面若只能说明“这是一家科技公司/这里有一枚火箭”，不能连续充当正文。每次切换画面应服务新的解释任务、证据、情绪或衔接功能。

## 7. 最后一次自审：五个不能通过的失败

1. **百科式开场**：先定义行业、车型或产品，没让观众看见异常代价。
2. **案例拼盘**：案例很多，却没有共同模型；删去任一案例也不影响结论。
3. **空吊胃口**：说“重点在后面”，后面没有更强证据或真正兑现。
4. **危机词替代机制**：用“崩了、内幕、资本游戏、颠覆”替代可解释的因果。
5. **中性资料片或无桥观点片**：要么没有判断，要么判断没有事实桥。

通过标准：观众能在不复看时说出“原来问题不在 X，而在 Y；下次我会看 Z”。
