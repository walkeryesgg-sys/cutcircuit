# 会员原声精选发布文案

仅适用 `member_source_curated` / 会员原声精选。不将中文口播、两次反转、独家分析或公开导流要求套在原声上。先核对选段与逐字稿，不能只根据片名写文案。

## 字幕身份与包装一致性

本系列明确使用英文原声＋中英文双字幕，视觉执行 [视频类型的字幕设计规范](../../produce-social-video/references/member-source-curated.md)。不得将“纯英文原声”误写为无中文字幕或仅英文字幕。可在发布信息中自然说明双语观看体验，但字幕卖点不能代替背景、内容、意义和思考。只有核验成片确有准确双语字幕后，才可在交付文案中宣称。

## 必须呈现的内容

1. 背景：人物、可核验时间、具体场合、内容形式（采访/演讲/对谈/内部讲话）、采访者或主持人，以及当时的必要处境。活动/录制时间、节目首播日期、网页更新日期与转载上传日期分开核验；只查到首播日时写“于某日首播的专访”，不能写成当天接受采访。只知年份就写年份，不补造月日。历史事件发生时间与访谈回顾时间也须区分。
2. 内容：这条精选实际讨论的问题、经历或机制；避免列出被剪掉的主题、称为完整演讲。
3. 意义：这个片段为什么值得现在观看，帮助理解哪个具体选择或方法。编辑解释明确归属于账号，不能冒充本人意思。
4. 思考：一条具体、可思考或应用的问题，来自视频中的真实取舍或边界。不要仅问“你怎么看”，不强造对立。
5. 出处：原节目/活动、原发布方、日期与链接；必要时指出历史预测/当时计划，并核验涉及现状的陈述。

最终输出默认采用下方四段结构；短内容可合并成2—3段，但不能删掉信息职责。长度按实际平台限制和信息需要决定，不机械凑字数。第一段优先提供可识别的背景和观看语境；结尾留下思考问题，来源单列可简洁附后。内部用背景/内容/意义/思考四项清单审计，用户文案不必显示四个栏目标题。资料未核实则交付标注待核验的草稿，不称可直接发布。

标题、封面、开头、描述必须兑现同一承诺。短标题沿用视频号少于16字的用户约束，不能把完整背景硬挤进短标题。润色执行 Humanizer，保留事实、限定条件、来源和编辑判断归属。会员文案默认无主页导流或订阅推销。

可选配套：一页背景/三条准确要点/一个应用问题/来源时间码、校对逐字稿。附加资料不能代替发布正文中的四项说明。

验收：逐项标出正文哪一句承担背景、内容、意义、思考；有任一缺项、空洞套话或未被成片支持的承诺，修订后再交付。


## 可复用发布模板（2026-09-19 用户确认的信息要求）

固定信息职责，不固定措辞。正文通常先写约300—500字再精简；这是编辑建议，不是平台限额。四段可不等长，不机械复刻连接词。

1. **背景**：这段影像来自〔时间〕的〔节目/活动〕。〔人物〕在〔场合〕接受〔谁〕采访／发表演讲／参与对谈，彼时〔一句必要处境〕。明确形式，节目首播日期与录制日期不可混写。
2. **内容**：这期精选围绕〔核心问题〕，保留〔成片中的两三个具体经历/解释〕。原声与双语形式可简洁说明，不能替代实际内容介绍。
3. **意义**：这段内容帮助理解〔具体选择/机制/代价〕；用〔实际片段中的细节或边界〕解释为什么选它。不能只写“经典、震撼、很有启发”。
4. **我们的思考**：明确归属账号的一点判断，随后留下一条由真实取舍产生的问题。意义回答“为什么值得看”，思考回答“我们如何理解、观众可继续追问什么”。不要以反问代替全部观点，不制造“坚持就必定成功”的保证。

末尾附系列/期数、原声与字幕身份、来源及选段说明、少量相关话题。完整发布包另保留原片链接与日期核验，公开描述按实际界面决定链接呈现方式。没有用户授权不执行发布。

包装同时交付：一个推荐发布标题、少于16字的视频号短标题、两种不同切入点的备选标题、可直接复制的描述、实际三比例封面。已有符合主题且经检查的封面可复用并说明；不用为了“生成”而重新制造纪录片人物影像。封面主文案表达一个处境/选择，小字补年份与节目/场合身份，完整背景留在描述，不把封面做成资料卡。
