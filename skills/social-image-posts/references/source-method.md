## 值得沿用

- 熟悉对象 + 平时看不见的结构：通勤地铁、家中冰箱、发动机等对象，比无对象的“震撼发现”更容易建立问题。
- 首图视觉负责吸引，内部解释负责知识回报，实用总结负责后续使用。收藏价值不能由“密密麻麻”代替。
- 依据主体选页面，不机械套用剖面、形成、生态、人类关系四件套。相同风格下可以改变视角与信息组织。
- 先以同一受众的三个关联问题试验小系列，跑通后再深入；保持问题变化，避免只替换地名的同质内容。
- 先核实层级、方向和结构再出图；非比例关系显著注明，精确地名、数值和空间位置需具体来源。
- 受众与后续服务相匹配。喜欢科普的读者不自然等于AI课程买家；营销目标须来自用户，不自动添加变现业务。

## 必须修正

| 原材料中的做法/说法 | 本技能的处理 |
|---|---|
| 单帖96.2万曝光、31.6万观看、15.4%封面点击率、29秒等 | 只作为作者自述个案。31.6÷96.2约32.8%，不等于15.4%；可能统计口径不同，不能直接判错，也不能混用 |
| 4917点赞、2690收藏，因此每两个点赞者有一个收藏 | 两个聚合计数不能推断用户交集；只可写收藏数/点赞数约0.55，不是收藏转化率 |
| 15.4%远高于平台平均、地域或科普天然长尾 | 未提供均值、样本选择、曝光来源和长期队列数据；作为作者解释/待测假设 |
| 米色图鉴背景、英文副标题、统一3D为强制 | 保留为可选风格；中文字阅读优先，英文装饰默认省略。主体和用户品牌决定方式 |
| 默认系列名“知识猫图解” | 不复制作者身份，改用用户品牌或原创系列名 |
| 张数一处4–8、一处4–7，完整版7 | 不继承矛盾；按实际问题确定页数，用户指定优先 |
| 同一seed保证一致 | 依赖后端；以锚图、视角、材质和结构约束建立一致性，不假装工具有seed参数 |
| Prompt里“8K”、`--v 6.1 --seed 24680` | 实测输出像素；专有参数仅在对应后端当前文档支持时使用 |
| 强行给非自然对象做“自然化拆解” | 组织和商业用明确的流程/关系隐喻，不能把隐喻冒充真实物理构造 |
| 图内每页重复同一句科学总结 | 改为每页新增结论，末页才汇总；避免重复页面拖延阅读 |

内容要有可以验证的发现，图像要让发现变得可见，平台适配要改变阅读体验，数据只用来检验假设。
