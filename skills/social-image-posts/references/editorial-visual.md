# 文案、页面与视觉决策

## 把信息变成读者的问题

先列三个候选角度，每个写具体对象、异常点、可核实答案、最能说明答案的画面、读者用途。按证据充分程度、视觉可解释性、受众相关性、区别于已有内容的发现选择。不要为了“最佳文案”同时堆五个钩子。

示例是写法演示，具体题材仍需重新核实：

| 弱表达 | 改写方向 | 为什么 |
|---|---|---|
| 火箭的底层逻辑，震撼认知 | 太空没有空气，火箭推什么？ | 对象和物理疑问明确，机制图能回答 |
| 这就是城市的秘密 | 地铁站台下面，还要留什么空间？ | 留下具体问题；必须先验证具体车站再下结论 |
| 99%的人不知道的黑科技 | 一台冰箱，怎样把热搬到屋外？ | 不编“99%”，动作即可带出反差 |
| 打破认知边界，开启探索之旅 | 删除，换成该页实际新增的一条结论 | 抽象感叹没有知识回报 |

不用每篇都写“原来不是X而是Y”。明确真实误解才纠正；没有误解就用“为什么/怎样/同样条件下有什么差别”。不编“我亲测、我去了现场、我花了三天”，资料整理可直接写“查了这份资料后，能看出……”且须真的读过。

## 页面模块库

从配套文章的动态模块思想归纳，编号仅供编排，不用暴露在成品里。

| 模块 | 使用条件 | 应避免 |
|---|---|---|
| 总览 | 建立对象、问题和初步答案 | 只有漂亮主体，没有信息 |
| 剖面/爆炸结构 | 有证据的内部层级/部件 | 凭空补管路，拿想象当内部图 |
| 形成过程 | 前后状态或条件真实可查 | 单图塞过多时间尺度 |
| 机制/流动 | 因果、物质、能量、信息流 | 箭头没有起终点或混用不同流 |
| 分布/位置 | 位置和范围能帮助理解 | 未核实地图边界、拿随机点作实测 |
| 尺度比较 | 量纲/比例是理解关键 | 装饰比例误导真实体积/长度 |
| 演化阶段 | 时间变化改变理解 | 未发生的阶段不标未来/预测 |
| 生态关系/循环 | 真实群落、环节或反馈 | 无生态对象也强凑食物链 |
| 人类用途/决策 | 与读者场景或取舍有关 | 强行添加灾难恐惧和营销 |
| 观测方法 | 不可直接看见、需仪器或模型 | 将模拟图称为望远镜照片 |
| 材料/微结构 | 组成解释性能 | 随机晶体、分子、比例 |
| 隐形力量 | 力场/压差等需要示意 | 把线画成实际物质或实拍 |
| 动态极端状态 | 事件本身确实有动态 | 用夸张灾难美术替代解释 |
| 误解纠正 | 有常见误解且可准确纠正 | 为反转捏造一个弱观点 |
| 自定义 | 现成模块不足以解释 | 只为凑页数新增模块 |

建议叙事：封面对象+初步发现 → 关键关系 → 如何发生 → 一个边界/对比 → 可复用结论。可以3页讲清就不用7页。每页回答一个问题，也制造一个自然的下一问；不能把“继续翻页”当内容。

## 选最能解释问题的视觉

| 内容需求 | 主视觉 | 具体设计 |
|---|---|---|
| 内部结构、地下层次 | 写实3D剖面/轴测图 | 1个主物体、真实层级、少量局部放大，切面能看清 |
| 工作原理 | 主体+有方向的路径图 | 以颜色区分流，说明图例；不装饰性堆箭头 |
| 真实事件/物件状态 | 许可清晰的原始照片/局部细节 | 文案解释看到了什么，生成图不能冒充现场证据 |
| 数字比较、账本 | 精确图表/原创排版 | 量纲、分母、范围和来源可见；3D透视不扭曲数值 |
| 组织/商业机制 | 流程或明确隐喻 | 标明组织关系示意；不伪造组织内部照片或结构 |

图鉴风可用暖米色、深蓝正文、自然材料色、微弱纸纹、清晰3D结构。现代工程风可用暖白、大留白、一个克制强调色。摄影风服从真实素材。根据主体择一，同系列保持；不默认可爱卡通，不锁死羊皮纸和英文副标题。

编辑数值均为起点：主视觉占约55%–70%；封面短句8–16字，副句不超过约24字；内页通常3–5处必要标注，约50–100字以内。复杂页通过拆分或局部放大解决，不靠缩字号。1080宽图正文可从42–54px尝试，源文/页码约28–32px，但最终以手机视觉检查为准。

先在约180px宽缩略图看对象和主标题能否辨识，再在360–430px宽手机大小读正文。预留边缘约6%、右侧/底部UI区随平台预览调整；这是设计余量，不是平台官方安全区。英文字母、长数字与单位不能自动挤爆布局。

引线只连到它解释的结构；颜色编码贯穿系列。必要提示直接在相关图片中出现：“AI生成·原理示意”“非比例示意”“未来设想”。“示意”不能豁免关键结构错误。
